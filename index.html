3. Synthesis pipeline & defect derivation

3.1 Code generation pipeline

Modern AI coding assistants utilize a 4-stage sequential execution pipeline that traverses from prompt ingestion through Abstract Syntax Tree (AST) context extraction to speculative multi-token decoding:

Prompt Ingestion ──► Context Retrieval (AST / Repo-Map) ──► Multi-Token Speculative Decoding ──► Linter / LSP Validation

3.2 Mathematical defect calculation

Defect density across committed code is calculated utilizing standardized IEEE software quality metrics:[1]

Defect Density = (Total Verified Bugs in Code Review / Total Lines of Code Committed) × 1,000 Example: 34 confirmed logic defects across 5,000 committed AI lines = 6.8 bugs per 1,000 LOC.
